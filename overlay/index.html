How to read this map

These are complete scientific source rasters. No arbitrary “top percent” mask removes CO, NOx, or temperature variation. Fire marker placement comes from NASA’s geographic EXR. Rainfall retains NASA’s native alpha. Continuous fields use uniform opacity to coexist above geography; selected layers become fully opaque above the base. This is exploratory visual composition, not a calibrated data fusion. Source acquisition times, map coverage and numerical scales remain distinct; matching aspect ratio does not establish identical scientific geotransforms. Use the provenance metadata in markers.json for context.
